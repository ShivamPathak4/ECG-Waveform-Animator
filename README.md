# ECG Waveform Animator (Custom Beats)

A React-based web application that simulates an Electrocardiogram (ECG) waveform. It allows users to adjust various parameters of ECG waves (P, QRS complex, T wave) and observe real-time changes. Additionally, it supports defining custom beat sequences for simulating irregular heart rhythms.

---

## 🚀 Features

- **Real-time ECG Waveform Display**  
  Animates a continuous ECG waveform on an SVG canvas with a grid background.

- **Adjustable Wave Parameters**  
  Control the height and breadth of P, Q, R, S, and T waves, and adjust segment lengths (PQ, ST, TP).

- **Heart Rate Control**  
  Modify the heart rate (in BPM) to observe its effect on waveform speed.

- **Dynamic R and P Wave Patterns**  
  Simulate arrhythmias by configuring repeating P or R waves after a set interval.

- **Custom Beat Sequences**  
  Define and repeat custom beats after a configurable number of normal beats.

- **Responsive Design**  
  Optimized layout for both desktop and mobile devices.

- **Modular Codebase**  
  Clean structure using React components and custom hooks.

---

## 🛠️ Technologies Used

- **React** – Frontend library
- **TypeScript** – For static typing and better developer experience
- **Tailwind CSS** – Utility-first CSS framework
- **SVG** – For precise waveform rendering
